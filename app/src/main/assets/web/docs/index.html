Ayuda y documentación

LocalShare facilita compartir archivos y contenido directamente a través de la red local. Lo mejor es que no se necesita conexión a Internet. Tus datos permanecen privados, completamente fuera de línea, y se transfieren a la velocidad máxima de tu Wi-Fi.

Los destinatarios no necesitan instalar ninguna aplicación. LocalShare es compatible con prácticamente cualquier dispositivo y sistema operativo (Windows, iOS, Linux, Android, etc.); solo necesitan un navegador web común en el dispositivo receptor.

Requisito de JavaScript: Actualmente, la interfaz necesita un navegador web con JavaScript activado. Estamos trabajando en una alternativa que no lo requiera para futuras versiones y así ampliar la compatibilidad.

Selección de archivos y contenido

LocalShare ofrece una forma flexible de poner tus datos a disposición de otros dispositivos de la red.

Compartir archivos

Puedes añadir archivos tocando el botón Más (+) dentro de la aplicación o usando el menú estándar de Android Compartir desde otra aplicación (por ejemplo, Fotos, Galería o el administrador de archivos).

Puedes organizar los archivos compartidos desde la pantalla principal o desde la pantalla Archivos, disponible en el menú.

Compartir texto

Para compartir texto, selecciónalo en cualquier aplicación y elige LocalShare en el menú Compartir de Android. También puedes pegar el contenido actual del portapapeles como una nueva entrada dentro de la aplicación.

Estos elementos se organizan en la pantalla Contenido compartido.

Start Sharing

Después de seleccionar los archivos o el contenido, toca el botón Iniciar servidor para ponerlos a disposición de la red local.

Cuando el servidor esté en funcionamiento, todos los elementos compartidos estarán disponibles en una interfaz web sencilla. Los destinatarios pueden conectarse escaneando el código QR o abriendo la URL proporcionada en su navegador.

Descarga ZIP

Los destinatarios pueden descargar todos los archivos compartidos de una sola vez en un único archivo ZIP. Esta función también funciona sin JavaScript.

Acceso sencillo

Comparte el enlace mediante cualquier aplicación de mensajería o permite que otras personas escaneen el código QR para conectarse al instante.

Actualizaciones dinámicas: Puedes añadir más archivos o contenido mientras el servidor está activo. Los elementos nuevos aparecen al instante en la interfaz web de todos los usuarios.

Consejo: ¿No tienes Wi-Fi disponible? Activa el punto de acceso móvil de tu teléfono y conecta el otro dispositivo a esa red. LocalShare funciona con tu propio punto de acceso, por lo que resulta útil para compartir archivos en el automóvil, en un avión o al aire libre.

Usos habituales

Transferencia rápida del teléfono al PC

Envía fotos, documentos y otros archivos desde tu teléfono a tu computadora al instante, sin buscar un cable USB ni usar servicios en la nube.

Reproducción de video en la red local

Reproduce películas o videos grabados desde tu teléfono en el navegador de una tableta, computadora o Smart TV, con posibilidad de avanzar y retroceder.

Presentación de fotos

Muestra las fotos de tus últimas vacaciones en una pantalla más grande con la función de presentación integrada en la interfaz web.

Distribución a varios dispositivos

Comparte archivos o notas con todo un grupo al mismo tiempo (por ejemplo, en una reunión o un aula). Todos deben escanear el mismo código QR.

Portapapeles entre dispositivos

Copia direcciones URL largas, contraseñas de Wi-Fi o fragmentos de texto en tu teléfono y accede a ellos desde tu computadora mediante la sección Contenido compartido.

Uso sin conexión a Internet

Ideal para viajes, aviones o zonas sin señal. Tu teléfono se convierte en un servidor local para los dispositivos cercanos.

Seguridad y privacidad

LocalShare está diseñado para proteger la seguridad y la privacidad de forma predeterminada:

Sin almacenamiento en la nube

Tus archivos no pasan por Internet. Las transferencias se realizan directamente entre dispositivos de la red local.

Tokens de acceso

El acceso está protegido por un token criptográfico. Solo quienes tienen el enlace o el código QR pueden acceder al contenido. Puedes renovar o cambiar el token manualmente en los ajustes.

Aprobación manual

Si activas esta opción, deberás autorizar manualmente las conexiones de nuevos dispositivos mediante una notificación en tu teléfono.

Nota técnica: seguridad en la red local

Los archivos se transfieren mediante HTTP (sin cifrado). Los navegadores modernos no aceptan certificados de seguridad para direcciones IP locales sin mostrar advertencias importantes de conexión no segura, lo que perjudicaría la experiencia de uso.

Recomendación de seguridad: Usa LocalShare únicamente en redes Wi-Fi privadas y de confianza. Evita compartir datos sensibles en puntos de acceso públicos o no confiables.

Preguntas frecuentes

¿Por qué mi dispositivo no encuentra el servidor?

Asegúrate de que ambos dispositivos estén conectados a la misma red Wi-Fi. Comprueba si las opciones «Aislamiento de clientes» o «Red de invitados» del router impiden la comunicación entre dispositivos locales.

¿Existe un límite para el tamaño de los archivos?

No. Como la transferencia se realiza localmente, solo está limitada por el espacio de almacenamiento disponible y la velocidad de la red.
